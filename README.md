# To-Do List App

A simple, elegant web-based to-do list application built with HTML, CSS, and JavaScript.

## Features

- ✅ **Add Tasks** - Easily add new tasks to your to-do list
- ✅ **Mark Complete** - Check off tasks as you complete them
- ✅ **Delete Tasks** - Remove tasks you no longer need
- ✅ **Persistent Storage** - Your tasks are saved in browser's local storage
- ✅ **Task Statistics** - View total and completed task counts
- ✅ **Responsive Design** - Works on desktop and mobile devices

## How to Use

1. Open `index.html` in your web browser
2. Type a task in the input field
3. Click "Add Task" or press Enter
4. Check the checkbox to mark a task as complete
5. Click "Delete" to remove a task

## Technical Details

- **Frontend Only** - No server required, runs entirely in the browser
- **Local Storage** - Tasks are saved in your browser's local storage (persists across sessions)
- **No Dependencies** - Pure HTML, CSS, and JavaScript (no frameworks)
